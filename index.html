03 A LITTLE ABOUT ME

MAKE IT USEFUL THEN MAKE IT BETTER ↗

I enjoy the point where clear thinking meets visible results: taking an idea, breaking it into small pieces, and turning those pieces into an interface people can actually use.

I’m self-taught in frontend development and currently building with JavaScript and React. I care about details that make a site feel finished — layout at smaller screen sizes, predictable interactions, readable structure, great functionality and states between clicks.

I prefer learning by building. Each project is a chance to test an idea, notice what feels awkward, and improve it with intention.
